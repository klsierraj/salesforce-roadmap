# Learn Salesforce from Scratch — Zero to Application & Integration Architect

Interactive **Vue 3 + Vite** engineering roadmap, hands-on lab tracker, glossary, and technical interview simulator designed for Full-Stack Developers transitioning into **Salesforce Development, RevOps, and Enterprise B2B Architecture**.

## Features

- **7 Progressive Engineering Blocks (`Block 00` → `Block 06`):**
  - **Block 00:** CRM Foundations, the Salesforce Ecosystem Map (Sales, Service, CPQ/Revenue, Data Cloud, Agentforce, MuleSoft), and Full-Stack Mental Models.
  - **Block 01:** B2B RevOps Funnel (`Lead` → `Account` + `Contact` + `Opportunity`), Data Model (`Lookup` vs. `Master-Detail`), Validation Rules, and Multi-Layer Security (`OWD`, `Sharing Rules`, `Profiles` & `Permission Sets`).
  - **Block 02:** Declarative Automation (`Before-Save`, `After-Save`, `Screen Flows`), the 14-Step Save Order of Execution, and the `Flow vs. Apex` Decision Matrix.
  - **Block 03:** Core Backend Engineering in `Apex`: Collections (`List`, `Set`, `Map`), Relational `SOQL`/`SOSL`, `DML`, Governor Limits, Bulkified Triggers, Async Apex (`@future`, `Queueable`, `Batch`, `Scheduled`), REST APIs, and `@IsTest` Suites (`>90%` coverage).
  - **Block 04:** `Lightning Web Components (LWC)`, `LDS`, `@wire` vs. Imperative Apex, `CustomEvent` & `LMS`, and GitHub Actions CI/CD.
  - **Block 05:** **Integration & IAM Architect Track:** The 6 Official Integration Patterns, Event-Driven Architecture (`Platform Events __e`, `CDC`, `Pub/Sub gRPC`, `Bulk API 2.0`), and `OAuth 2.0 JWT Bearer Flow` / `SAML SSO`.
  - **Block 06:** **Application Architect Track:** Large Data Volumes (`LDV >50M rows`), Index Selectivity, eliminating `Data Skew`, and internal `__Share` table architecture.
- **Interactive Master Glossary (`A–Z`):** Core Salesforce concepts mapped directly to their Full-Stack equivalents.
- **Technical Interview Simulator:** Categorized flashcards with Senior-level answers and local mastery tracking.
- **Direct Code Translator:** Side-by-side comparison of `TypeScript / SQL / React` vs. `Apex / SOQL / LWC`.
- **Responsive Design:** Desktop sidebar + mobile/tablet slide-over drawer.

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:4324` in your browser.
